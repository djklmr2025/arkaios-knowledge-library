## 🌟 Visión del Proyecto

Esta plataforma **no es solo un reproductor o videoteca convencional**: es un **Motor de Navegación Cognitiva y Enciclopedia Tecnológica para Agentes de IA**.

Cuando un usuario o un sistema orquestador le indica a un agente de IA:
> *"Explora el museo de conocimiento..."*

El agente tiene la capacidad autónoma no solo de reproducir contenido multimedia de **Facebook (`facebook.com/arkaiosIA`), TikTok y YouTube**, sino de:
1. **Entender el contexto tecnológico profundo** de cada lección.
2. **Descubrir repositorios de GitHub oficiales** asociados (como herramientas open-source, motores en Rust, alternativas a software privativo).
3. **Identificar y asimilar nuevas habilidades operativas** (Model Context Protocol - MCP, reverse-engineering, protocolos P2P, robótica).
4. **Integrar ese conocimiento a su memoria de trabajo** para evolucionar como un mejor agente.

## 🛠️ Herramientas CLI para Agentes de IA

### 1. Explorador Cognitivo (`agent_navigator.js`)
```bash
# Explorar toda la enciclopedia y repositorios indexados
node agent_navigator.js explore

# Inspeccionar a fondo un tema, repositorio o tecnología
node agent_navigator.js inspect artcraft

# Asimilar la lección técnica en la memoria cognitiva del agente
node agent_navigator.js learn artcraft
```

### 2. Extractor Universal Zero-Key (`media_extractor.js`)
Extrae metadatos, lecciones y contexto de cualquier publicación o video sin requerir credenciales ni llaves API:
```bash
node media_extractor.js "https://www.facebook.com/share/p/..."
```

### 3. Sincronizador de Publicaciones y Videos (`sync_worker.js`)
```bash
# Sincronización única manual
node sync_worker.js

# Monitoreo autónomo cada 15 minutos (modo Daemon)
node sync_worker.js --watch 15
```
